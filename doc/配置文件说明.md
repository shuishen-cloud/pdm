# 配置文件说明

配置文件路径（按优先级从高到低）：

| 来源 | 路径 | 是否进 git |
|------|------|-----------|
| CLI 参数 | `pdm --store xxx ...` | — |
| 环境变量 | `PDM_*` | — |
| 项目配置 | `.pdm.json`（从当前目录向上查找） | 是，团队共享 |
| 用户配置 | `~/.config/pdm/config.json` | 否，个人偏好 |
| 默认值 | 内置 | — |

**配置文件必须是标准 JSON**（不支持注释）。格式错误会明确报错并退出，不会静默忽略。

---

## 顶层字段

| 字段 | 类型 | 默认 | 说明 |
|------|------|------|------|
| `store` | string | `"notes"` | 笔记存储目录。相对路径按配置文件所在目录解析 |
| `default_author` | string | `"human:unknown"` | 记笔记时的默认作者；命令行 `-a` 可覆盖 |
| `color` | bool | `true` | 是否彩色输出。非终端或 `--json` 时自动关闭 |
| `editor` | string | `""` | 默认编辑器（预留） |

## `note`

| 字段 | 类型 | 默认 | 说明 |
|------|------|------|------|
| `default_status` | string | `"noted"` | 新建笔记的默认状态：`open` / `resolved` / `noted` |
| `require_detail` | bool | `false` | 为真时，缺少 `--detail` 的笔记会被拒绝 |

## `query`

| 字段 | 类型 | 默认 | 说明 |
|------|------|------|------|
| `default_limit` | int \| null | `null` | 查询默认返回条数；`null` 表示不限 |

## `git`

| 字段 | 类型 | 默认 | 说明 |
|------|------|------|------|
| `repo` | string | `"."` | git 仓库路径 |
| `auto_commit` | bool | `false` | 记录笔记后自动提交 `notes/`（预留） |

## `issue`

| 字段 | 类型 | 默认 | 说明 |
|------|------|------|------|
| `store` | string | `"issues"` | Issue 存储目录（预留） |

## `doc`

| 字段 | 类型 | 默认 | 说明 |
|------|------|------|------|
| `dir` | string | `"docs"` | 文档目录（预留） |

## `feat`

Feat（开发记录：设计→测试→实现→fix）的存储。

| 字段 | 类型 | 默认 | 说明 |
|------|------|------|------|
| `store` | string | `"feats"` | feat 存储目录，一条一文件（`by-id/<slug>.json`） |

## `ui`

TUI（`pdm ui`）的外观与交互。

| 字段 | 类型 | 默认 | 说明 |
|------|------|------|------|
| `theme` | string | `"textual-dark"` | 内置主题名；见 `pdm theme` 列表 |
| `commit_width` | int | `0` | 提交条目最大宽度；`0` = 跟随面板宽度 |
| `show_footer` | bool | `true` | 是否显示底部快捷键栏（预留） |

主题可在 TUI 里直接改（`t` 循环切换 / `T` 选择器）或命令行 **`pdm theme <名字>`**，
改动会**自动写回配置文件**（优先项目 `.pdm.json`，没有则写用户配置）。

内置主题（21 个）：`textual-dark`、`textual-light`、`nord`、`gruvbox`、
`dracula`、`monokai`、`tokyo-night`、`catppuccin-mocha`、`catppuccin-latte`、
`catppuccin-frappe`、`catppuccin-macchiato`、`rose-pine`、`rose-pine-moon`、
`rose-pine-dawn`、`solarized-dark`、`solarized-light`、`atom-one-dark`、
`atom-one-light`、`flexoki`、`ansi-dark`、`ansi-light`。

```json
{ "ui": { "theme": "nord", "commit_width": 60 } }
```

## `github`

| 字段 | 类型 | 默认 | 说明 |
|------|------|------|------|
| `repo` | string | `""` | GitHub 仓库，如 `user/repo`（预留） |
| `token` | string | `""` | **不要写在此处**，改用环境变量 `PDM_GITHUB_TOKEN`（预留） |
| `auto_push` | bool | `false` | 自动推送（预留） |

> 标「预留」的字段目前会被读取和保存，但尚未接入功能逻辑。

## 环境变量

| 环境变量 | 对应配置 |
|----------|---------|
| `PDM_STORE` | `store` |
| `PDM_AUTHOR` | `default_author` |
| `PDM_EDITOR` | `editor` |
| `PDM_NO_COLOR` | 置 `color = false` |
| `PDM_JSON` | 置 `json_output = true` |
| `PDM_GIT_REPO` | `git.repo` |
| `PDM_GIT_AUTO_COMMIT` | `git.auto_commit` |
| `PDM_ISSUE_STORE` | `issue.store` |
| `PDM_DOC_DIR` | `doc.dir` |
| `PDM_FEAT_STORE` | `feat.store` |
| `PDM_UI_THEME` | `ui.theme` |
| `PDM_UI_COMMIT_WIDTH` | `ui.commit_width` |
| `PDM_QUERY_DEFAULT_LIMIT` | `query.default_limit` |
| `PDM_GITHUB_REPO` | `github.repo` |
| `PDM_GITHUB_TOKEN` | `github.token` |
| `PDM_GITHUB_AUTO_PUSH` | `github.auto_push` |

布尔值接受 `1` / `true` / `yes` / `on`（不区分大小写）。

## 示例

**项目级 `.pdm.json`（团队约定）：**

```json
{
  "store": "notes",
  "default_author": "human:alice",
  "note": {
    "default_status": "open",
    "require_detail": true
  },
  "query": {
    "default_limit": 20
  }
}
```

**用户级 `~/.config/pdm/config.json`（个人偏好）：**

```json
{
  "color": false,
  "ui": {
    "theme": "nord"
  }
}
```

> `pdm theme <名字>` 或 TUI 里按 `t` / `T` 会自动写入这里
> （有项目 `.pdm.json` 时写项目那份）。

**临时覆盖：**

```bash
pdm --store /tmp/my-notes note add abc123 -k pitfall -t "标题"
PDM_STORE=/tmp/my-notes pdm note add abc123 -k pitfall -t "标题"
```

## 关于注释

配置文件**必须**是标准 JSON，不支持 `//` 或 `/* */` 注释。

原因：`.pdm.json` 可能被编辑器、`jq`、CI、其他语言脚本读取，宽松解析会带来兼容性问题和调试困惑。

如需字段说明，参考本文件；如需便携式速查，可在配置旁边放一个非配置名的说明文件（如 `.pdm.json.md`），不要用注释。
